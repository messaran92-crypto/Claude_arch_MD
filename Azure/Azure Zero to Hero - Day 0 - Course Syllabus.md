# Azure Zero to Hero - Day 0: Course Syllabus

## Overview

This is the Day 0 introduction for the Azure Zero to Hero course. The instructor explains the complete learning roadmap, how the course is structured, and what learners can achieve by the end of the series.

The main goal is to make the learner job-ready for Azure and DevOps roles and also prepare them for Azure certifications such as AZ-900 and AZ-104.

---

## Course Vision

The course is designed to teach Azure from the ground up, starting with cloud fundamentals and then moving into Azure-specific services.

The key idea is simple:

- start with the basics
- build strong foundations
- move into practical Azure services
- connect theory with hands-on demos/projects
- prepare for interviews and certifications

The course is planned as a 25-day roadmap, with Day 0 acting as the course orientation and roadmap video.

---

## Why Cloud Fundamentals Come First

Before jumping into Azure, the instructor emphasizes that learners should understand core cloud concepts.

These include:

- virtualization
- virtual machines
- APIs
- regions
- geography
- availability zones
- scalability
- elasticity
- agility
- high availability
- disaster recovery
- load balancing

The goal is to make these terms familiar so that later Azure explanations feel easier and less confusing.

This is especially important because many people hear terms like API, VNet, load balancer, or region without understanding the real-world meaning.

## Day-Wise Learning Roadmap

### Day 1: Cloud Computing Fundamentals

This session introduces the foundational cloud concepts needed for any cloud platform.

Topics included:

- virtualization
- virtual machines
- APIs
- cloud architecture basics
- core cloud terminology
- scaling and resilience concepts

The course emphasizes understanding the vocabulary before learning Azure-specific implementation details.

### Day 2: Getting Started with Azure

This day covers:

- creating an Azure account
- understanding Azure regions and availability zones
- Azure IAM models like IAM, SAS, and access considerations
- overview of Azure services

The learner starts to understand how Azure organizes and exposes cloud services.

### Day 3: Resources, Resource Groups, and Azure Resource Manager

This is a very important Azure concept.

Topics covered:

- what is a resource in Azure
- what is a resource group
- what is Azure Resource Manager
- how resources are created and managed in Azure

This helps learners understand the structure behind every Azure deployment.

### Day 4: Virtual Machines and VM Scale Sets

This part focuses on compute in Azure.

Topics covered:

- what is a virtual machine
- how to create a VM in Azure
- how to connect to the VM
- how to deploy an application on a VM
- what is VM scale set
- how autoscaling works in Azure

### Day 5: Azure Networking Basics

Networking is treated as a highly important topic.

This section includes:

- virtual networks
- subnets
- CIDR ranges
- route tables
- network security groups (NSGs)
- application security groups
- real-world traffic flow examples

The instructor explains these concepts using a real-world analogy so they are easier to understand.

### Day 6: Advanced Azure Networking

This day goes deeper into network connectivity and architecture.

Topics covered:

- VNet peering
- VNet Gateway
- VPN Gateway
- Azure Load Balancer
- Azure Application Gateway
- Azure CDN

The difference between Azure load balancer and Application Gateway is explained clearly.

### Day 7: Interview Questions and Answers

This is a checkpoint to revise foundational Azure and cloud concepts.

The instructor says this is important because many Azure interview questions test understanding of:

- cloud basics
- Azure networking
- VMs and compute fundamentals

This helps learners evaluate how much they actually understand before moving further.

### Day 8: Two-Tier Application Deployment Project

This is the first practical project.

The learner will deploy a two-tier application on the Azure platform.

This project helps connect the earlier networking and VM knowledge into a real deployment workflow.

### Day 9: Azure Storage Services

This day focuses on Azure storage.

Topics include:

- storage accounts
- types of storage services
- usage scenarios
- practical demonstrations

Storage is one of the main Azure services that every cloud engineer should understand.

### Day 10: Azure CLI

This is the first automation-focused section.

The learner learns:

- how to use Azure CLI
- how to automate Azure resource creation
- how to interact with Azure from scripts

This is important for DevOps engineers because automation is a core responsibility.

### Day 11: Azure Templates

This section introduces Azure Resource Manager templates.

It teaches:

- infrastructure as code using templates
- declarative deployment
- how to create and manage resources in a repeatable way

### Day 12: Authentication and Identity Management

This is a security and access-focused section.

Topics may include:

- authentication basics
- identity management in Azure
- RBAC
- access control concepts

The instructor notes that Azure identity works a bit differently from AWS, so it is best explained after learners know the platform well.

### Day 13: Monitoring and Resource Observability

This day focuses on how to monitor resources in Azure.

Topics include:

- where to view resource activity
- how to understand what was created or changed
- basic Azure monitoring concepts

### Day 14: Azure DevOps Introduction

This is the first Azure DevOps-focused video.

It introduces:

- what Azure DevOps is
- the different services it provides
- Azure Repos
- Azure Boards
- CI/CD concepts

### Day 15: Azure DevOps CI Project

This section covers continuous integration implementation.

The learner learns how to set up a build pipeline and automate validation.

### Day 16: Azure DevOps CD Project

This day focuses on continuous delivery.

The project is designed around a virtual machine environment.

### Day 17: Azure Kubernetes Service (AKS)

This section introduces AKS.

Topics include:

- what is AKS
- how it differs from Kubernetes basics
- how applications are deployed to AKS
- how to expose applications externally with Ingress

### Day 18: Three-Tier Architecture Project on AKS

This is a major real-world project.

The instructor explains a 3-tier e-commerce-style application with multiple services, including:

- multiple microservices
- databases
- caching
- message queue
- Dockerfiles
- deployment workflow
- ingress setup

This is a more realistic and comprehensive deployment scenario.

### Day 19: Azure DevOps Interview Questions

This is a checkpoint dedicated to Azure DevOps interview preparation.

It helps learners assess whether they understand the DevOps concepts they have learned.

### Day 20: Azure Key Vault

This is a crucial security topic.

The learner learns how to store sensitive information securely in Azure, such as:

- secrets
- keys
- certificates

### Day 21: Serverless and Azure Use Cases

This is a very important and future-focused area.

The instructor explains why serverless is valuable for DevOps engineers and how it helps with:

- cloud cost optimization
- compliance requirements
- automation
- scalable event-driven systems

Two practical projects are mentioned:

- cloud cost optimization
- compliance implementation

### Day 22: Terraform on Azure

This is where infrastructure automation with Terraform is introduced.

The learner learns:

- how Terraform connects with Azure
- how to create Azure resources with Terraform
- how to manage state files

### Day 23 to Day 24: Continued Azure Automation and Advanced Infrastructure Topics

The transcript refers to the later stages of the roadmap, where the course continues to focus on practical Azure automation and real-world DevOps patterns.

### Day 25: Azure Interview Preparation

This final day is about career readiness.

The instructor explains:

- how to present projects on a resume
- how to communicate Azure experience clearly
- how to answer Azure interview questions
- how to showcase real hands-on work

## What the Learner Should Be Able to Do After Completing the Course

The instructor says the final outcome of the series is that a learner should become job-ready for Azure and DevOps roles.

The course is ideal for people who want to work in:

- Azure DevOps roles
- Azure cloud engineering roles
- DevOps + Azure positions

The course is not meant to replace the entire DevOps learning path, but it complements it well.

- networking

- virtual networks
- storage
- compute

- security
- governance

The course covers all of these topics through lectures and practical projects.
